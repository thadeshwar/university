# USC 2.0 — School of AI

A one-year, self-run university. Sept 2026 – Sept 2027. Zero to frontier in AI/ML theory, application, and engineering.

**The site (course catalog, calendar, progress):** deployed via GitHub Pages from `index.html`.

## This repo is the transcript

Every notebook typed, every cheat sheet written, every project shipped — it all lands here. No copy-paste, no downloads of other people's solutions. If it's in this repo, I built it.

## Layout

- `term1-foundations/` — math cheat sheets context + Karpathy Zero to Hero notebooks (micrograd → makemore → GPT)
- `term2-core-ml/` — CS229 problem sets, MIT 6.S191 work, Hugging Face course notebooks
- `term3-llms/` — CS224N + CS336 assignments (the crown jewels)
- `term4-rl-systems/` — RL work, efficient-ML labs, capstone
- `cheatsheets/` — one page per math course, maximum
- `projects/` — Project 1 (QLoRA fine-tune), Project 2 (RAG), Project 3 (agent), capstone. Each with its eval defined **before** the build.
- `eng30/` — daily engineering half hour: Exercism solutions, Missing Semester notes, Docker files, and eventually ML system design notes
- `index.html` — the university site
